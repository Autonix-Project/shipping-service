# AUTONIX Shipping Service
- Simulator Kafka 이벤트를 받아 상품 출고 등록
- Order와 OpenFeign 동기 통신으로 주문 정보 조회
- 배송 상세 조회(타임라인, 목적지)
- 배송 상태 확인(출고대기/배송중/배송완료)
